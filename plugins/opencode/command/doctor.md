---
description: Checkup of all AI CLIs — installed, logged in, fixes, free options, switch default
---

Run `npx smart-switcher doctor` with the bash tool and relay the result simply:
connected agents, problems with the exact fix command, and free agents worth
adding.

If the user passed arguments ($ARGUMENTS):
- a CLI name → run `npx smart-switcher use $ARGUMENTS`
- `<cli> <model>` → run `npx smart-switcher model <cli> <model>`
